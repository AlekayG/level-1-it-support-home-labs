
# Level 1 IT Support Home Labs

## About This Repository

This repository documents my hands-on learning and practical labs in IT support. The goal is to develop and demonstrate the technical skills required for Level 1 Help Desk and IT Support roles.

## Projects

### 1. Active Directory and User Management
- Practise creating and managing user accounts.
- Organise users into organisational units and security groups.
- Simulate password resets and account access issues.
- Document domain setup and user administration procedures.

**Status:** In progress

### 2. Windows Troubleshooting
- Investigate common Windows operating system issues.
- Practise diagnosing network connectivity problems.
- Use built-in tools to investigate performance and service issues.
- Document troubleshooting steps and verified resolutions.

**Status:** Planned

### 3. Help Desk Ticket Simulations
- Document simulated IT support incidents.
- Record symptoms, troubleshooting steps, findings and resolutions.
- Practise writing clear technical notes and escalation summaries.

**Status:** Planned

## Tools and Technologies

- Windows 10/11
- Windows Server
- Oracle VirtualBox
- Active Directory Domain Services
- Create Active Directory lab documentation
- Command Prompt and PowerShell
- GitHub and Markdown

## Learning Approach

Each project will include its objectives, lab environment, practical steps, troubleshooting findings, verification results and supporting screenshots.

All activities are performed in a personal lab environment using fictional users and test data.
